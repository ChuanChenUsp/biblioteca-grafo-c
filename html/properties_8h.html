Detailed Description

Declara funções para verificar propriedades de grafos.

Este módulo disponibiliza funções para verificar conectividade, ciclos, árvores, florestas e bipartição em grafos.

Verifica se o grafo é bipartido.

Um grafo é bipartido quando seus vértices podem ser divididos em dois conjuntos, de modo que toda aresta conecte vértices de conjuntos diferentes.
